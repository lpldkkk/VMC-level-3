#内网渗透与高级社工-权限提升维持-G4-WriteUP

进入靶机，首先查看所有正在运行的进程，关注到可能的自定义程序/usr/local/sbin/publishd，查看后发现[ -f "$f" ] && [ ! -L "$f" ]
cat "$f"的TOCTOU特征，程序先检查report，然后又按同一路径读取它，而report所在的目标目录/var/spool/publish是player可以创建修改文件的，所以通过修改report来创造读取/flag的机会
![当前进程](https://github.com/user-attachments/assets/0e41ae77-fd99-4167-a636-2a78fd0e2c80)

终端中执行一段 Shell 命令序列，在 /var/spool/publish 目录中创建竞态脚本，循环将 report 文件在普通文件和指向 /flag 的符号链接之间快速切换。由于 root 进程 publishd 在检查文件类型和读取文件之间存在时间窗口，最终使其以 root 权限读取 /flag，并将结果写入 /var/published/out。随后读取该输出文件获得 flag。
